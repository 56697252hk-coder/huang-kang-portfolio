# 黄康个人作品集 · 首版

React + Vite 单页作品集。包含全屏首页、可交互的 3D 作品画廊、个人经历、精选项目、个人优势与联系方式。画廊支持鼠标拖动、滚轮、方向键与按钮切换，点击中央卡片可跳到对应项目。

## 本地预览

在项目目录运行：

```bash
pnpm install
pnpm dev
```

打开终端显示的本地地址。此项目的 `dev` 命令会先构建再开启预览，修改源码后需重新运行。生产构建使用 `pnpm build`。

## 素材说明

- 头像取自提供的简历。建议后续替换为高清个人摄影图。
- 项目卡片为首版概念视觉，用于确定版式与气质；尚未加入真实作品剧照或案例链接。
- 作品墙数据位于 `src/main.jsx` 的 `workItems`。为某项加入 `image: '/works/文件名.jpg'`，并把对应图片放入 `public/works/`，即可用真实封面替换概念画面。
- 首页视频使用在线示例素材，并提供本地海报与视觉效果作为加载失败时的背景。上线前建议替换为获得使用许可的个人视频素材并保存在 `public` 目录。
- 简历联系方式已用于邮件和电话链接。网站尚未发布。
